# Оператор

*Тема джема: конец неизбежен*

**Платформа:** мобильная · **Арт:** только генерация · **Вид:** 2D сбоку

---

## Суть

Подземный мир на время **одной игры** + база **Ярмо** на поверхности Керна `(0, 0)`.

Спускаешься по заданию **VIYA**, ставишь **сканеры ресурсов**, копаешь **открытые** скопления, **сам едешь назад** по тоннелю. На базе — склад и прокачка. Снова в ту же шахту, глубже. Тоннели живут **в рамках одной игры**. Мёртвые дроны прошлых клонов **остаются на планете между играми** — можно найти, если докопаться.

Внизу — **ядро / конец**. Добраться почти нереально: лазер режет глубже, корпус — нет.

---

## Петля

1. На базе VIYA выдаёт **миссию** (установить **сканер ресурсов** или добыть скопления).
2. Спуск с базы → выполнение на карте (бурение, установка сканера, сбор).
3. Вернулся на базу → сдача миссии, разгрузка, ремонт, прокачка; следующая миссия.
4. Новый спуск в **ту же** шахту. Тоннели и установленные сканеры на месте.

**Топливо = 0** вне базы → **смерть, game over** (дрон на `(X, Y)`, груз теряется). **Заряд = 0** — не копаешь, но по тоннелю можешь ехать. **Отсек полный** — руда **не забирается**, звук отбоя (как у непробиваемой стены).

**Кнопки «На базу» нет.**

После **смерти** вне базы — **game over**. Дальше только **новая игра**: новый мир (seed, R, тоннели), прокачка и журнал с нуля. **Глобально** сохраняются: **рекорд глубины** и список **мёртвых дронов-клонов** на координатах планеты.

---

## Управление

- D-pad: **↑ ↓ ← →** — езда и бурение во все четыре стороны.
- Установка **сканера ресурсов** в целевом секторе (миссия VIYA).
- Возврат = физически доехать до **Ярмо** `(0, 0)`.

---

## Дрон

Мир и коллизии — на **сетке клеток** (`int X`, `Y`). **Не пошаговая игра:** позиция в мире — **непрерывная** (float), логика породы и save — в клетках.

### Состав

```
Drone
├── Bur          (корпус)
└── LaserBeams   (лазерные головки, по сторонам корпуса)
```

Отдельного выдвижного сверла (**Bit**) нет — копание только **лазером**. Отдельной кнопки «бурить» нет.

### Позиция на сетке

- **Клетка дрона** — по **центру корпуса**: `Round` мировых координат (одно правило на весь проект; согласовать с якорем тайлмапа).
- В **тоннеле** (воздух) можно **остановиться в любой точке** внутри клетки.
- В **породу** заезжать нельзя — только прорезать. Половинок клеток в логике нет.

### Движение

- Езда **непрерывная**, не «ход за нажатие».
- В свободной клетке — полная скорость (тратит **топливо**).
- Поворот и езда — **разные действия** (см. ниже).
- Ось **X** с wrap планеты — через нормализацию координаты клетки, не телепорт.

### Бурение лазером (без остановки)

Держишь направление D-pad **в сторону породы** — лазер режет **соседнюю клетку**; дрон **не останавливается** специально ради бура.

| Ситуация | Поведение |
| -------- | --------- |
| Впереди **воздух** | Обычная езда, полная скорость |
| Впереди **порода** + жмёшь в эту сторону | **Режим бурения:** едешь **медленнее** (топливо **× множитель**, меньше чем в тоннеле); лазер бьёт клетку — **заряд**; падает HP породы |
| Клетка стала **воздухом** | Без паузы — дальше на полной скорости |
| **Заряд = 0** | В стену не пройти; стоишь у породы |
| Пласт **не режется** (уровень лазера) | Упёрся в стену |
| Отпустил ввод | Торможение, бурение прекращается |

**Целевая клетка** — сосед в сторону ввода от клетки дрона: `(cellX + dx, cellY + dy)`; по **X** — с `wrap`.

Скорость в режиме бурения — **ниже**, чем в тоннеле (отдельный параметр; позже **привод** ускоряет разрушение блока). Визуально — плавное «прожигание» коридора, без stop-start на каждой клетке.

### Поворот на месте (360° за **0.15 с**, ввод заблокирован)

Скорость: **2400°/с** — полный оборот за 0.15 с; поворот на 90° ≈ 0.0375 с.

Смена направления корпуса:

1. Корпус **крутится** (`rotation` по Z).
2. Лазеры **не убираются** — остаются на корпусе.

Поворот **не сдвигает** дрон. Езда **не крутит** корпус — отдельные действия.

## Модули

Прокачка **только на базе**. Апгрейд = **смесь ресурсов**, не один тип.

### Лимиты (на один спуск)


| Модуль            | Что даёт          | Тратится на / поведение вне базы                     |
| ----------------- | ----------------- | ---------------------------------------------------- |
| **Топливо**       | запас хода        | **любое движение**; в тоннеле — полный расход, при бурении — **меньше** (медленнее). **0 = смерть** |
| **Заряд**         | энергия лазера    | **только** бурение породы (твёрже = дороже). **0** — не копаешь, по тоннелю едешь |
| **Отсек**         | объём груза       | **1 ед.** за клетку жилы с рудой (позже — камень с породы). **Полный** — не подбираешь, звук отбоя |
| **Прочность**     | выдержка давления | пассивно: чем глубже, тем быстрее; у поверхности ≈ 0. **0 = смерть** (позже) |
| **Жаростойкость** | выдержка жара     | пассивно: растёт с глубиной. **0 = смерть** (позже) |

### Прогресс (между спусками)


| Модуль      | Эффект                                |
| ----------- | ------------------------------------- |
| **Привод**  | быстрее ломается блок                 |
| **Лазер**   | какие пласты режутся                    |
| **Локатор** | направление на **открытые** скопления в зоне сети сканеров; дальше с уровнем |


**Лазер** не убивает — просто не режется пласт без нужного уровня. **Прочность / жар** — убивают, если залез слишком глубоко без прокачки.

---

## Пласты

**8 пород**, **8 уровней лазера**. Лазер уровня **N** режет пласты **1…N**; без нужного уровня — не копается.

Глубина пласта — **% от R** (радиус мира). Мир **ч/б**; пласты отличаются **тоном и фактурой**. Цвет — только у **открытых** жил (после миссии на добычу).

| Лазер | Порода | Y (% от R) |
| ------ | ------ | ---------- |
| 1 | **Край** | 0–8% |
| 2 | **Осад** | 8–15% |
| 3 | **Накипь** | 15–25% |
| 4 | **Свод** | 25–55% |
| 5 | **Каркас** | 55–68% |
| 6 | **Жиль** | 68–80% |
| 7 | **Мантия** | 80–92% |
| 8 | **Ореол** | 92–100% |

На `Y = R` — **ядро** (не порода, конец карты). **Де-ваульт** чаще в глубоких пластах (Ореол, Мантия).

## Ресурсы (MVP)

**Порода и камень** — видны сразу (процедурная генерация по seed). Копаешь «пустую» породу — цветных жил нет.

**Жилы (скопления руды)** — **не видны**, пока VIYA не выдала миссию на добычу в этом секторе. После выдачи миссии скопления **появляются визуально** в породе (пачки из нескольких клеток). **Не восстанавливаются** после добычи. С породы ничего не сыпется — только жилы.

Добыча и прокачка идут **через миссии VIYA**; свободного фарма без задания нет.

| Ресурс | Цвет | Назначение |
| ------ | ---- | ---------- |
| **Синтет** | зелёный | прокачка |
| **Реллит** | синий | прокачка |
| **Люмин** | жёлтый | прокачка |
| **Де-ваульт** | багровый, перелив | для VIYA — «пакет на Землю»; редкий, глубже, отголосок **ядра** |

Апгрейд = **смесь** Синтет + Реллит + Люмин. **Позже:** другие руды.

## Миссии VIYA и сканеры ресурсов

Задания выдаёт **VIYA** на базе. Игрок видит цели в **секторах** (`D15 R8`), не в сырых клетках. Детали сетки секторов — `TECH.md`.

### Сканер ресурсов

Оборудование миссии: **установить сканер** в указанном секторе и **вернуться на базу**. Только после сдачи VIYA «получает данные» с этого узла.

- Один сканер освещает зону **3×3 сектора** (центр — сектор установки).
- Миссии на **добычу** VIYA даёт **только** в секторе, который уже в зоне действующей сети сканеров.
- У ствола на старте игры — **стартовая сеть** (или первая миссия — ближний сектор под Ярмо), чтобы не было тупика.

VIYA в репликах: калибровка сети, связь с Землёй, выход руды. Реальный смысл сети — в лоре открывается обрывками; в механике сканер **разблокирует** добычу в регионе.

### Типы миссий (MVP)

| Тип | Суть |
| --- | ---- |
| **Установить сканер** | доехать до сектора → установить → вернуться на базу |
| **Добыть скопления** | VIYA сообщает тип руды и сектор; жилы **включаются** при выдаче; нужно добыть N **скоплений** (пачек) |

Шаблоны миссий задают **ограничения** (тип, глубина, дистанция от шахты), а не фиксированные координаты. Конкретный сектор и клетка — **roll из seed** при выдаче (см. ниже). Жёсткий сектор/клетка — только **сюжетные исключения**.

### Планирование миссий и достижимость

VIYA выдаёт миссию **на базе**, когда у дрона **полные** лимиты (топливо, заряд, пустой отсек). Цель миссии не должна быть «в камне без пути» и не должна съедать весь запас впритык.

**Шаблон** (`MissionTemplate`): диапазоны `depthMin…depthMax`, `lateralMin…lateralMax` (|R| от ствола; L/R не в ассете — знак из seed). Клетка внутри сектора — детерминированный roll. Секторы уже сданных миссий — не роллить повторно.

**Планировщик** (тот же seed + каталог): для каждого кандидата симулирует спуск **база → цель → действие → база** и принимает только **достижимые** варианты. Формулы расхода — **те же**, что в геймплее (см. конфиг лимитов дрона).

#### Бюджет одного спуска

| Ресурс | Когда тратится |
| ------ | -------------- |
| **Топливо** | **любое движение** по маршруту: воздух — `fuelPerCell`; бурение — `fuelPerCell × drillFuelMultiplier` (медленнее → меньше) |
| **Заряд** | **только** вырезание породы лазером (твёрже → дороже) |
| **Отсек** | **+1** за каждую добытую **клетку жилы** с рудой (позже — камень с породы) |

- **Туда:** порода — **топливо (мало) + заряд**; воздух — **топливо (полное)**.
- **Обратно:** по коридору — **только топливо** (всё воздух).
- **Установить сканер:** доп. расход **нет** (0 заряда, 0 груза) — только доехать и поставить.
- **Добыть N скоплений:** заряд на **вырезание** клеток жил + **отсек** под все клетки руды в этих пачках. Отсек полный → клетку можно вырезать, но **руда не забирается** (звук отбоя).

#### Запас (safety margin)

VIYA не жмёт впритык: планировщик требует, чтобы после миссии оставался запас **10–20%** от каждого лимита (топливо, заряд, свободный отсек). Игрок может съездить в сторону, объехать червя, ошибиться с поворотом. Доля запаса — **в конфиге** (настраивается, в т.ч. с прокачкой баков).

#### Числа и прокачка

Все коэффициенты выносим в **конфиг** (`DroneLimitsConfig`): `fuelMax`, `chargeMax`, `cargoMax`, `fuelPerCell`, `drillFuelMultiplier`, `chargePerRockTier[]`, `cargoPerVeinCell` (обычно 1), `missionSafetyMargin`. Прокачка на базе увеличивает ёмкости — планировщик при выдаче читает **текущие** значения сессии.

Планировщик **не учитывает** на первых итерациях: прочность, жар, червей, магнитные аномалии (добавим позже).

Детали roll и BFS — `TECH.md`.

### Акт 1 (обучение, черновик)

1. **×3** — установить сканер (три разных сектора).
2. **×3** — добыть по **2 скопления**: Синтет, Реллит, Люмин (каждая в секторе своего сканера).
3. Награда — прокачка **лазера** до уровня 2.

Дальше тот же ритм: расширение сети сканеров на новый фронт → добыча в освещённой зоне → апгрейды. Не обязательно 3+3 каждый раз — плотная цепочка только в акте 1.

### Журнал и локатор

- **Журнал** — ведётся **автоматически** (игрок ничего не добавляет вручную): миссии VIYA, установленные сканеры, открытые скопления, прогресс добычи, сданные задания. Записи в **секторах** (`D15 R8`).
- **Локатор** — намёк на открытые скопления в зоне сети; без сканеров и без миссии жил нет.

### Лор (границы)

VIYA **не** выдаёт миссии про мёртвых клонов и «чёрный ящик» — это находки на карте и обрывки правды, не каталог заданий.

## Черви (после MVP)

Подземные **линии-змейки** по клеткам. От **лазера не убиваются** — только **убегать**.

| | |
| --- | --- |
| **Движение** | Строго по сетке (↑↓←→), сегменты как в змейке; тик раз в ~0.35 с |
| **Где** | **Везде** — сквозь породу и воздух; база и ядро — нельзя |
| **Spawn** | Детерминированно от seed + глубины (как жилы); длина **5–15** сегментов |
| **Wander** | Полупрозрачная линия (~фиолетовая, alpha ~0.35) |
| **Attack** | Багровое **мигание** + преследование (задел; урон позже) |

**Отрисовка:** `LineRenderer` между **RockBack** и **RockFront** — в тоннеле и «в массиве» породы.

## Карта

- Чанки по мере движения, всё сохраняется в рамках **одной игры** (в памяти — только окрестность игрока).
- Координаты в **клетках** — **единая сетка Керна**:
  - **X** — горизонталь по поверхности планеты (wrap на краях);
  - **Y** — глубина вниз от поверхности (`Y = 0` у ствола, вниз = больше).
- База всегда **`(0, 0)`**. Спавн на `(0, 0)`.
- **Новая игра** — новая генерация мира; тоннели, сканеры и открытые жилы прошлой игры **не переносятся**.
- **Мёртвые дроны** — глобальный save, отдельно от мира: объекты `(X, Y, номер клона)`. В новой игре на тех же координатах — если докопаешься.

### Размер мира
    
При **первом создании** мира один раз выбирается радиус **R** (случайно **10 000–15 000** клеток). Сохраняется в сейве, для этого мира не меняется.

Система координат (поверхность `Y = 0`):

| Ось | Диапазон | На краю |
| --- | -------- | ------- |
| **X** | `−R` … `+R` | **wrap** — обход планеты по горизонтали |
| **Y** | `0` … `+R` | **ядро / дно**, дальше нельзя |

**X — кольцо планеты.** Дошёл до `+R` и идёшь вправо → оказываешься на `−R`: ты на **другой стороне** планеты, не под текущей Ярмо. С `−R` влево → `+R`. Лор: подземный путь вокруг чужой планеты.

**Y — только вглубь.** Выше `0` не копаем (поверхность). На `Y = R` — конец карты, ядро. Wrap по Y **нет**.

Порода — процедурная генерация по `(X, Y)` и seed мира. Жилы **материализуются** при выдаче миссии на добычу (детерминированно от seed + сектор). Изменения игрока (воздух, добытая руда, сканеры) — save **текущей игры**. Отдельно — глобальный save: рекорд глубины + мёртвые дроны.

## База

- Название станции: **Ярмо** (лор, UI). На спрайте базы **надписей нет**.
- AI станции: **VIYA** — *Virtual Integrated Yield Assistant* (англ. расшифровка; «yield» = добыча, выход руды). Лор, UI, реплики.
- Поверхность, экран склада + прокачки + **миссии VIYA**.
- Позиция фиксирована: **`(0, 0)`**. Не двигается между играми.
- Въехал в зону 1–2 клетки у **`(0, 0)`** → полный ремонт, заправка, разгрузка рюкзака.

## Планета

- **Керн** — чужая планета, на которой разбилась экспедиция и стоит **Ярмо**.
- Экспедиция летела **на другую цель**; после крушения остались здесь.

---

## Лор

Колония на **Керне** — станция **Ярмо** на поверхности, внизу шахта до ядра.

Экспедиция потерпела крушение. На станции остался **VIYA** — бортовой AI «Ярмо»; со временем **сошёл с ума**.

Игрок — **оператор**: по заданиям VIYA расширяет **сеть сканеров** и добывает руду; позже — **де-ваульт**. VIYA называет это отправкой на Землю; на деле — чтобы **продолжать существовать**. Операторов **клонируют** — каждая новая игра, новый клон. Старых клонов можно **найти на карте** — мёртвые дроны на координатах прошлых смертей.

VIYA общается **текстом**: реплики, «связь с Землёй», сообщения, истории — **ложь**, чтобы держать оператора в работе. Правда открывается **постепенно** (заметки, логи, находки; в т.ч. мёртвые дроны прошлых клонов). **Когда** именно — не фиксируем.

Внизу — **ядро** / конец карты. Финал — позже.

---

## Тема

Конец неизбежен как **направление вниз**: чем больше Y, тем больше топлива, корпуса и жара. Лазер открывает путь — но не гарантирует возврат.

- [ ] **Сканеры ресурсов** + миссии VIYA (установка + добыча скоплений)

## План разработки

### Принцип

Вертикальные срезы: каждый этап — играбельный кусок, который можно проверить в редакторе или на телефоне.

Порядок: **мир → дрон → камера → сохранение → экономика → база → смерть → сканеры и миссии → прогресс**.

Сетка в **клетках** (`int X`, `int Y`): мир, порода, save, UI — в клетках. **Движение дрона** — непрерывное (float); бурение — без остановки, режим медленной езды вперёд (см. **«Дрон»**).

### Структура проекта

**Контент** (не код):

```
Assets/Game/
  Scenes/     — игровые сцены
  Sprites/    — спрайты, тайлы, фоны
  Scripts/    — см. ниже
```

`Assets/Settings/` — URP и шаблоны сцен, не трогать без нужды.

**Скрипты** — каркас на корне `Scripts/`. Игровые модули — папки рядом (`Depth`, `Surface`, `Player`…). Внутри модуля — **Core** (чистый C#, без `MonoBehaviour`) и **Unity** (`MonoBehaviour`). Namespace = путь папки (`Operator.Depth.Core`, `Operator.Surface.Unity`).

Не MVP из веба: граница не Model/View, а **«зависит от сцены?»**.

```
Scripts/

Bootstrap/                     ← старт приложения и уровня
  GameBootstrap, LevelBootstrap

Data/                          ← каркас: общие данные
  AssetPack, WorldSession, BackgroundPack…

Managers/                      ← сервисы и оркестрация
  GameManager, AssetManager, TextManager, AudioManager, InputManager

Depth/                         # домен: подземный мир (карта)
  Core/      World, Chunk, CellData, WorldGenerator
  Unity/     DepthWorld (tilemap)

Surface/                       # домен: поверхность
  Unity/     SurfaceBackground

Parallax/                      # общий модуль (не домен)
  Core/      ParallaxMotion
  Unity/     ParallaxLayers

Drone/                         # актор: корпус, лазеры
  LaserBeam/  → Unity/

UI/, Enemies/                  # позже
```

**Namespace:** `Operator.Data`, `Operator.Managers`, `Operator.Bootstrap`, `Operator.{Module}.{Core|Unity}`.

**Домен vs актор:** `Depth` / `Surface` — **мир**. `Player` — **кто ходит по миру**. `Parallax` — переиспользуемая отрисовка, не игровой домен.

**Подпапки внутри Core** — когда в модуле много файлов, группировка по теме:

```
Depth/Core/
  Generation/      WorldGenerator.cs, OreVeins.cs
```

Правило: подпапка = **тема**, не слой. Слой уже задан (`Core` / `Unity`).

**Куда класть новый файл:**

| Что | Куда |
| --- | --- |
| enum, struct, SO, save для 2+ модулей | `Data/` |
| чистый C#, без `MonoBehaviour` | `{Module}/Core/` |
| `MonoBehaviour`, привязка к сцене | `{Module}/Unity/` |
| общий модуль (parallax и т.п.) | `Parallax/Core` или `Parallax/Unity` |
| связка систем | `Managers/` |
| старт приложения / уровня | `Bootstrap/` |

### Этапы

#### 0 — Скелет проекта

- Папки по **«Структура проекта»** выше.
- Сцена: Camera, корневой `Game`, Canvas (заглушка).
- Решение: координаты мира в клетках; дрон ездит непрерывно по свободным клеткам.

**Чекпоинт:** пустая сцена с камерой и UI-заготовкой.

#### 1 — Сетка + бурение

- **World:** тип клетки (порода / воздух), HP, копание.
- **Drone:** непрерывная позиция; клетка дрона по центру корпуса; лазер режет **соседнюю** клетку по вводу, **без остановки** (медленнее в режиме бурения).
- Визуал: Tilemap или спрайты — данные отдельно от отрисовки.
- Генерация: фиксированный столб под `(0, 0)` (земля вниз, по бокам камень). Процедурка породы — позже; жилы — с миссиями VIYA.
- Камера следует за дроном; ось Y сцены = глубина (клетки).

**Чекпоинт:** D-pad → копаешь тоннель, на экране видна глубина.  
*Закрывает пункт MVP: сетка, бурение, камера, глубина.*

#### 2 — Чанки + save

- Чанк 16×16 клеток, ключ `(chunkX, chunkY)`.
- Подгрузка вокруг дрона, выгрузка далёких.
- Save: только изменённые чанки (JSON / файл).
- Пока без руд — только земля / воздух.

**Чекпоинт:** накопал → перезапуск → тоннель на месте.  
*Закрывает пункт MVP: чанки + save карты.*

#### 3 — Движение по тоннелю + топливо + заряд

- **Тоннель:** езда на полной скорости (топливо); стоп в любой точке свободной клетки.
- **Порода впереди:** режим бурения — едешь медленнее, лазер бьёт соседнюю клетку (заряд), **без stop-start**.
- UI: полоски топливо / заряд.
- `заряд = 0` → в стену не пройти; по готовым тоннелям едешь, если есть топливо.

**Чекпоинт:** выкопал коридор, проехал назад — ресурсы убавились.  
*Часть MVP: топливо + заряд.*

#### 4 — База

- Зона 1–2 клетки у **`(0, 0)`** = база.
- Въехал → полный refill лимитов, конец спуска. Без телепорта.

**Чекпоинт:** спустился, вернулся пешком — снова полный бак.  
*Закрывает пункт MVP: база без телепорта.*

#### 5 — Смерть + мёртвый дрон

- **Топливо = 0** (и позже **прочность / жар = 0**) **вне базы** → смерть, **game over**. Дрон замирает на `(X, Y)`, попадает в **глобальный** список (X, Y, номер клона).
- **Новая игра:** новый мир, прокачка и журнал с нуля. Глобально остаются рекорд глубины и мёртвые дроны.

**Чекпоинт:** умер внизу — дрон на месте, game over; новая игра — другой мир, старый клон на координатах если докопаешься.  
*Закрывает пункт MVP: смерть + мёртвый дрон.*

#### 6 — Отсек + ресурсы (по миссии)

- **Отсек:** **1 ед.** за клетку жилы с рудой; отсек полный → не забираешь, **звук отбоя** (как у непробиваемой стены). Позже — камень с породы по той же схеме.
- Жилы появляются только после миссии VIYA на добычу; до этого порода без цветных скоплений.

**Чекпоинт:** по заданию появились жилы → выкопал → груз в отсеке.  
*Часть MVP: отсек + 4 ресурса.*

#### 7 — Лазер + привод

- **Лазер:** уровни 1…8 по таблице пластов. Не режется пласт без нужного уровня.
- **Привод:** скорость разрушения блока.

**Чекпоинт:** без апгрейда глубже пласта не копается.  
*Закрывает пункт MVP: лазер, привод.*

#### 8 — Склад + прокачка

- Экран базы: склад + апгрейды.
- Апгрейд = **смесь ресурсов**, не один тип.

**Чекпоинт:** накопил ресурсы → прокачал модуль → следующий спуск сильнее.  
*Закрывает пункт MVP: прокачка за смесь ресурсов.*

#### 9 — Сканеры + миссии VIYA

- **Сканер ресурсов:** установка в секторе, зона 3×3, сдача на базе.
- Миссии: установка (×3 в акте 1) → добыча скоплений (Синтет / Реллит / Люмин).
- Roller + Resolver: сектор из seed, жилы при выдаче миссии.

**Чекпоинт:** акт 1 пройден → лазер 2 доступен.  
*Закрывает пункт MVP: сканеры и миссии.*

#### 10 — Журнал + рекорд глубины

- **Журнал:** авто-запись при выдаче/сдаче миссии, установке сканера, открытии и добыче скоплений.
- Рекорд максимальной глубины — **глобально**, между играми.

**Чекпоинт:** журнал обновляется сам по событиям, рекорд сохраняется.  
*Закрывает пункт MVP: журнал, рекорд глубины.*

### После этапа 10 (MVP готов)

Прочность, жаростойкость, локатор (уровни), остальные руды, де-ваульт в цепочках, финал у ядра.

3. Спрайт дрона, D-pad из четырёх кнопок.

Без save, руд и базы — только копание и глубина.
