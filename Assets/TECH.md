## Сетка

- Клетки `X`, `Y`. База `(0, 0)`. Y вниз = глубже. Метров нет.
- **32×32 px**, **PPU 32** → 1 клетка = 1 юнит.
- **World ↔ cell только через `WorldGrid`** (не сдвигать Grid/Depth в инспекторе «на глаз»).
- **Depth/Grid/Tilemap** на сцене: transform `(0,0,0)`, TileAnchor `(0, 0.5)`.
- **TilemapRenderer:** при таком TileAnchor тайлы визуально выходят за AABB чанка; если **Chunk Culling Bounds** `(0,0,0)` — на краю камеры может быть полоска фона. В `SampleScene`: **Detect Chunk Culling Bounds** вкл. или вручную **X = 0.5** (как `HalfCell`).
- Клетка `X` → world X от `X` до `X+1`; тайлы и дрон по **левому краю** X; дрон по **центру** Y (`DroneCellToWorld`). Константы — `WorldGrid.CellSize`, `HalfCell`, `SceneTileAnchor*`.

### Границы мира

- **R** — при создании мира, случайно `10 000…15 000`, хранить в save.
- **X:** `−R…+R`, на краю **wrap** (`+R` + вправо → `−R`, `−R` + влево → `+R`).
- **Y:** `0…+R`, без wrap; `Y > R` и `Y < 0` — нельзя.

Движение по X с wrap — через нормализацию координаты, не телепорт под базу.

### Seed и карта

- **Seed** — одно число при новой игре. Из него **детерминированно** выводится порода, жилы, якоря пачек: одна и та же `(seed, x, y)` → одно и то же содержимое клетки.
- **R** — радиус мира в клетках (глубина `0…R`, горизонт `−R…+R`). Один раз на игру, в save.
- Карта **не хранится целиком в RAM**: `World.GetCell(x, y)` + чанки с **изменениями игрока** (выкопано, жила добрана). Остальное вычисляется по формуле, **не рисуется** до refresh вокруг камеры.
- **Новая игра** → новый seed → другой мир. **Внутри одной игры** мир фиксирован.

### Секторы

**Два слоя координат:**

| Слой | Где используется | Видит игрок? |
| ---- | ---------------- | ------------ |
| **Клетка `(x, y)`** | движок: бурение, коллизии, `World.GetCell`, save чанков | **нет** |
| **Сектор** | HUD, миссии VIYA, журнал, локатор «куда ехать» | **да** |

Игрок **всегда** понимает мир через **сектор**: где он сейчас и в какой сектор ведёт миссия. Клетки — только внутренняя математика (пересчёт сектор ↔ клетка в коде).

**Размер сектора:** **100×100 клеток**.

**Привязка:** ствол Ярмо = `(0, 0)` в клетках. Глубина — только вниз (Y растёт). Горизонт — влево / вправо от ствола; wrap по X как у мира.

**Адрес сектора (отображение):**

- **D** — номер сектора по **глубине** (0 у поверхности, дальше 1, 2, 3…).
- **L** — секторы **влево** от ствола; **R** — **вправо**.
- Пробел между частями. Без `:` и `,`.

| Ситуация | Пример |
| -------- | ------ |
| Под стволом | `D7` |
| Со смещением | `D15 R8`, `D7 L4` |

**L / R не пишем**, если дрон под стволом (не `L0`, не `R0`).

**Навигация:** сравни свой адрес с целью — больше **D** → глубже (вниз); **L**/**R** и число → влево/вправо на N секторов.

**Компактный id** (save, журнал): `D15R8`, `D7L4`, `D7` — без пробелов.

**Пересчёт:** позиция дрона (клетка) → сектор для HUD; цель миссии в секторе → rect клеток для Resolver (жила внутри сектора).

## Камера

- Orthographic, **size ~10**, **портрет** (вид сбоку, ось Y сцены = глубина вниз).
- У поверхности экран делится **сверху вниз** (не слева направо):
  - **верхняя 1/3** — фон (parallax);
  - **нижние 2/3** — порода / тоннель.

## Поверхность (parallax)

**Ассеты:** `Resources/Asset Packs/Surface Background Parallax` — спрайты **по порядку в списке**: индекс `0` = небо (дальний план), дальше — ближе к камере. В паке только картинки. Ярмо — отдельный объект на сцене.

**Скорости:** `parallaxSpeeds[]` в `ParallaxBackground` (на объекте Background), по одному значению на слой.

**Когда видно:** только у поверхности (`Y ≈ 0`). Спустился — **скрыть** (позже).

## Смерть и save

- **Смерть вне базы** → game over. Дрон остаётся на `(X, Y)`.
- **Сейв игры** (seed, R, чанки, прокачка, журнал) — только в рамках одной игры; при новой игре сбрасывается.
- **Глобальный сейв** — рекорд глубины + список мёртвых дронов `(X, Y, номер клона)`. Не сбрасывается между играми.

**Скрипт:** `Parallax/Unity/ParallaxBackground` на Background — слои из пака, `ParallaxLayers` крутит скролл.

## Дрон

Мир и коллизии — на **сетке клеток** (`int X`, `Y`). **Не пошаговая игра:** дрон **едет непрерывно** по свободным клеткам и может **остановиться в любой точке** внутри клетки, если она пустая (воздух / тоннель). Движение по X с wrap — через нормализацию координаты.

Дизайн дрона и поворота — **`GDD.md` → «Дрон»**. Здесь — числа и сцена.

### Состав

```
Drone
├── Bur          (корпус, ~28–30 px; на сцене может называться иначе, например Sprite)
└── LaserBeams   (лазерные головки, дочерние объекты корпуса)
```

Выдвижного сверла (**Bit**) нет.

### Поворот на месте (360° за **0.15 с**, ввод заблокирован)

1. Корпус **крутится** (`rotation` по Z).
2. Лазеры **не убираются**.

Скорость: **2400°/с**. Поворот **не сдвигает** позицию. Езда **не меняет** угол корпуса.

Половинок клеток в логике нет.

### Движение

Непрерывное внутри клетки; коллизии и порода — по сетке. Отдельно от поворота (см. выше).

## Миссии (VIYA) — зафиксировано, не в коде

**Не** ручные координаты на каждую игру. **Шаблоны** (ScriptableObject / конфиг) + **seed** текущего мира.

### Шаблон миссии (автор пишет один раз)

- Тип: `InstallScanner`, `MineClusters` …
- **Сектор:** `depthMin…depthMax`, `lateralMin…lateralMax` (|R| от ствола; L/R — roll из seed). Не фиксировать `D`/`L`/`R` в ассете, кроме сюжетных `fixed`.
- Добыча: ресурс, `mineClusterCount`.
- Текст VIYA: `{resource}`, `{amount}`, `{sector}` …
- Сюжетные миссии — `fixed` сектор/клетка без roll.

### При выдаче миссии

1. **Roller** — из `seed` + шаблона + индекс миссии → сектор и клетка в допустимых диапазонах.
2. **Reachability** — симуляция спуска (GDD → «Планирование миссий»): **топливо** — на каждую клетку движения (воздух полное, порода × `drillFuelMultiplier`); **заряд** — на бурение породы; отсек — `cargoPerVeinCell` × клетки руды в N пачках (оценка по `resourceClusterSizeMax`); запас 10–20%. Сканер — без доп. расхода.
3. **Resolver** — для добычи: якорь жилы в секторе (`ResourceClusterGenerator.TryGetSectorVein`), тип совпадает с миссией.
4. **Save** — `ActiveMission`: сектор, `(x,y)`, прогресс. Не полная карта.

Конфиг: `fuelPerCell`, `drillFuelMultiplier`, `chargePerRockTier[]`, `cargoPerVeinCell`, `missionSafetyMargin`, ёмкости с прокачки.

### Жилы и миссии

- Жилы — **пачки** (якорь + несколько клеток). Для миссии достаточно якоря или «любая клетка пачки с типом X».
- После бурения жила в `CellData` сбрасывается; save чанка помнит изменение.

### Порядок в коде (когда дойдём)

1. Жилы в `CellData` + генерация пачек.
2. `MissionTemplate` + `MissionRoller` + `MissionResolver`.
3. UI VIYA / журнал / локатор — **сектор** (`D15 R8`); указатель на зону сектора, не на «клетку −12300».
